# Figure2c 新配色

本目录的绘图脚本从「数据」重新生成圆环图，输出到「图」。原版文件未修改。

## 配色与尺度

NSF 色带采用 Figure1a 的 `#E4EDF5 → #7F99B2 → #003366`；NSFC 色带采用 `#F6E4E4 → #C57F7F → #8B0000`。差值环沿用这组深、中红蓝色锚点，零点为 Figure1a 的 `#ECEFF1`。对应的色标随色带同步更新。

本图原有的 NSF/NSFC 统一 0–100% 尺度和差值 −60 至 +60 个百分点尺度保持不变。Figure1a 对另一组数据使用 0–70% 的截顶尺度，此处保留 0–100%，避免裁掉本图最高约 80% 的单元。路径顺序、扇区大小、六个任务组、黑色分组框及显著性标记均未改变。

## 文件与复现

- `代码/绘制Figure2c_配对圆环图.py`：绘图入口。
- `代码/独立复核Figure2c_圆环图.py`：独立数据及 SVG 检查。
- `数据/`：原数据副本及路径语义索引。
- `图/`：同名 PDF、SVG、600 dpi PNG、600 dpi TIFF 和快速预览。
- `复核/`：逐单元渲染核对表、绘图检查及独立复核结果。
- `说明/来源文件清单.json`：10 份源数据的路径与 SHA256。

运行绘图代码需要 numpy、pandas、matplotlib、Pillow。两个脚本均按自身所在目录定位文件。

## 检查

独立复核通过 60 项：54 条路径、324 个路径任务组合、972 个实际色块、34 个统计标记、36 个分组框、完整 bootstrap 区间与 BH 校正、SVG 色值及 600 dpi PNG 均已检查。绘图检查未发现越界文字或图例文字重叠；已目视检查红蓝深浅层次与 Figure1a 的视觉一致性。
