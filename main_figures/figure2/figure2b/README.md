# Figure2b 新配色

绘图脚本从本目录的原始数据重新生成四象限图，输出到「图」。原版文件未修改。

## 配色

象限底色按平衡后差值的方向排列：上半区为蓝色、下半区为红色。I、III 象限保留原色；II 由浅紫改为浅蓝 `#E5EEF6`，IV 由浅黄改为浅红 `#F8E9E9`。点、椭圆、坐标、标签、面积编码和统计定义不变。

## 文件与复现

- `代码/绘制Figure2b_四象限与环节椭圆.py`：绘图入口；同目录的 `sci_style.py` 为样式依赖。
- `代码/独立复核Figure2b.py`：不导入绘图代码的独立数据及导出检查。
- `数据/`：4 份源数据及绘图脚本再生的 4 份明细、统计表。
- `图/`：同名 PDF、SVG、600 dpi PNG。
- `说明/`：来源哈希、绘图对象记录、独立复核结果及预览。

运行绘图代码需要 numpy、pandas、matplotlib；独立复核需要 pypdf、Pillow。两个脚本均按自身所在目录定位数据与输出文件。

## 检查

独立复核通过 55 项：311 个 SVG 点与源数据一一对应，坐标、点面积、象限计数、椭圆参数、9 个标注、4 个象限底色、PDF 版心及 600 dpi PNG 均已检查。原始输入的 SHA256 与来源副本相同；已目视检查标签、图例和对比度。
