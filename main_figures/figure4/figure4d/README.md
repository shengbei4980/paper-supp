# Figure 4c：双横轴共用画框重绘版

## 图面结构

整图采用一个连续画框。**顶横轴直接位于画框上边**，范围为 0–35，控制浅色背景横条的绝对平方 Aitchison 距离。**底横轴位于画框下边**，范围为 −50% 至 +50%，控制前景方向化贡献标记和区间；底轴的零位在画框中央。两轴使用同一绘图区与逐行位置。

框内顶部依次显示两国总体 `A²`，以及各国排名前三的 SDG 合计 `A²`；后一组条末同时标注其占该国总体 `A²` 的比例。下方 12 个 SDG 各设 NSF、NSFC 两行：浅色条长为该国该 SDG 的 `M_count²`，彩色前景干线与圆点表示带符号的贡献份额。细线端帽是项目族 bootstrap 的贡献**幅度** 95% 区间，按点估计的 `M_count` 方向镜像显示；方向是否稳定由原稳定性门另行判定，未通过者的前景标记用灰色。

图中 NSF 蓝色为 `#3775BA`，NSFC 红色为 `#B64342`；背景条使用两色的淡色阶。标有 `(d)` 的 SDG 与 Figure 4d 展开项一致。顶部两个汇总量占据独立的行，但不使用内部小图或第二个画框。

## 数据与复现

- `数据/`：保留从上级 Figure 4c 冻结的 9 个原始数据与来源文件；`figure4c_dual_axis_plot_data.csv` 是绘图代码根据冻结数据生成的 28 行图层数据（4 个汇总行、24 个 SDG 行）。
- `代码/plot_figure4c_integrated.py`：只读取本目录数据；前三位绝对量按 `A² × top3_share / 100` 确定，没有重新估计原统计量。
- `图/Figure4c_双横轴叠层重绘.*`：PNG 300 dpi、SVG、PDF、TIFF 600 dpi LZW。SVG/PDF 保留可编辑文字。
- `QA/复核结果.json`：运行时数值与导出检查；`QA/原始数据哈希比对.csv`：冻结源文件的 SHA-256 对照。

本机可使用 `conda run -n py311 python 代码/plot_figure4c_integrated.py` 复现。代码也可在装有 Matplotlib、Pandas、NumPy、Pillow 的 Python 环境中运行。

## 已核对的关键数值

| 国家 | 总体 A² | 前三位 A² | 前三位占比 | 12 项贡献份额之和 |
|---|---:|---:|---:|---:|
| NSF | 21.3229 | 11.7650 | 55.1752% | 100% |
| NSFC | 31.6150 | 22.3269 | 70.6211% | 100% |

24 个国家—SDG 单元各有 2,000 次项目族 bootstrap 汇总。每国 12 项 `M_count²` 之和等于其总体 `A²`；各国前三项 `M_count²` 之和等于图示前三位绝对量。正式输出的原始状态字段随冻结数据保留，本重绘只改变图面编码。
