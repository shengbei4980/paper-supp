## 设计与读图

严格沿用 Figure 1a 源代码的国家配色：NSF 点和文字为深蓝 `#003366`、区间为中蓝 `#7F99B2`；NSFC 点和文字为深红 `#8B0000`、区间为中红 `#C57F7F`。这些标记与 Figure 1a 的实色柱一样使用不透明颜色。横轴是 NSF 减 NSFC 的百分点差，六个分面采用完全相同的坐标范围和零参考线。线段与端帽表示原有的 95% Bootstrap 区间；实心点表示该区间不跨零，空心点表示跨零。空心点仍以估计值的正负着红蓝边色。四个原图强调的数值继续标注。

六个领域标题逐项读取 `领域任务原始结果.csv` 的 `domain_label` 原文，包括 D02、D05、D06 的完整名称。图内删除 K01–K06 代码标签，使用不含代码的任务短名；图下任务全称逐项读取原始数据的 `knowledge_label`。

每个分面右上角的 `9/17 paths` 等是“至少一个任务满足路径区间及 BH-FDR 条件的路径数／纳入路径数”。它们是路径层级的描述，不能当作领域层面的多重检验结论。图中没有新加领域 FDR 星号，也没有将跨零区间隐藏。

ModelViz 候选中选择了“带显著性标记与误差棒的环形柱状图”作为不确定性标记的起点。由于此处要比较 36 个有正负方向的差值，适配时保留点、区间和分组的视觉语法，将径向位置改为共用尺度的笛卡尔分面；不使用模板中的柱形或显著性字母。原始模板未修改。

## 建议替换的图注

**图 S6｜六类城市需求领域的知识任务差异。** 每个点表示在全局 Target—时间平衡后，同一需求领域内 NSF 与 NSFC 的条件知识任务份额之差（NSF 减 NSFC，百分点）；横线为原有 Bootstrap 95% 百分位区间。蓝色表示 NSF 份额较高，红色表示 NSFC 较高；空心点的区间跨零。六个领域共用横轴尺度，完整展示 K01—K06 的 36 项估计与区间。领域内的路径计数为至少一个任务满足路径区间与 BH-FDR 条件的路径数／纳入路径数，不能解释为领域层面的显著性检验。领域份额汇总自全部项目的领域贡献，并非展示路径的等权平均。
