# Supplementary tables and indexes

This directory contains the supplied summary/lookup tables, grouped by manuscript panel, plus generated English navigation tables:

- `panel_index.csv`: current figure/panel IDs, descriptive figure titles, actual file counts, and repository locations.
- `coding_label_lookup.csv`: unique English field names, definitions, category codes, and category labels extracted from the full coding-evidence exports.

No new manuscript Table S numbers are assigned. Other analytical CSVs, including complete estimates and bootstrap draws, remain in `data/processed/`; per-file schemas are indexed in `supplementary_doc/provenance/csv_inventory.csv`.
