## 3 推荐的单画框结构

采用一张连续矩阵、一个外框及一个色带。纵向为19项需求，顺序沿用代码本；横向为三个列组，顺序固定为相对低位、近似相称、相对高位。每组有K01—K06六个效应列和一个窄ESS信息列。

```text
                         相对低位              近似相称              相对高位
需求名称                 K01…K06  ESS          K01…K06  ESS          K01…K06  ESS
┌──────────────────────────────────────────────────────────────────────────┐
│ N01 气候适应与极端风险降低     全部差异单元，统一尺度，需求逐行对齐           │
│ …                                                                        │
│ N12 建筑、交通与产业减碳       主文案例在行标签中加粗                         │
│ …                                                                        │
│ N19 城乡联系与跨区域协调                                                   │
└──────────────────────────────────────────────────────────────────────────┘
           一个红—中性—蓝色带；一个稳定性与低支持图例
```

矩阵含342个效应色块和57个支持量读数；ESS信息列不是新增检验单元。三组之间只用两条细分隔线，不再使用三个独立外框、三个独立支持度轴或宽空隙。

建议起始尺寸为183 mm通栏宽、高约125—135 mm，左侧需求标签预留约45—50 mm；主体字号以约7 pt为起点。此为排版设计值，最终尺寸须在正式制作时检验，不能以压小字体实现紧凑。若完整标签需要两行，应增加行高并保持所有列组同一行高。

## 4 逐项简化方式

| 当前表达 | 推荐处理 | 保留的科学信息 |
|---|---|---|
| 三个热图画框与较大间隔 | 共用一个外框，内部两条细分隔线 | 三类别独立识别，逐行可比较 |
| 三条完整英文类别长标题 | 用“Lower / Near-aligned / Higher”短标题；图注完整定义 | 相对配置类别及阈值 |
| 需求只显示N01—N19 | 左侧显示代码及有明确含义的需求名称；长名称规范换行 | 19项需求及代码本对应 |
| 每个稳定单元同时有框、点，部分还有数字 | 去掉35个黑框，保留35个稳定点 | 原稳定性判定逐单元保留 |
| 每类一组对数支持度侧条 | 改为同一矩阵中的窄ESS数值列 | 57个较小ESS读数及其大小关系 |
| 每个低支持格重复多条斜线 | 对相应六任务整行采用稀疏细斜线 | 全24个低支持组合仍可直接辨认 |
| 任意挑选每类最大差值写数字 | 取消这套标注；在下方给一条正文减碳案例读数 | 不影响任何色块或源表中的精确估计 |
| 多行分析说明及冗长底部文字 | 图面保留差值定义、必要图例；详细调整和推断规则移入图注 | 方法、分母与统计定义完整保留 |

ESS≥10显示整数近似；ESS<10显示一位小数并加低支持标记。低支持状态必须依据未四舍五入的原值判定；接近10的值采用向下保留一位小数，避免9.96显示10.0造成误读。精确ESS仍在源表提供。ESS列使用中性文字和白底，不使用红蓝效应色带。

保留六个需求领域的原有行排序，领域边界改为细浅灰线。N12的需求行标签加粗即可，不增加局部放大窗、连线或覆盖热图的背景带。

## 5 配色及数值幅度

继续使用红—中性—蓝的连续发散色带，零值居中：红色表示NSFC条件任务份额较高，蓝色表示NSF较高。类别标题使用中性深灰，避免类别“相对高低”与国别差异的红蓝方向混淆。

当前数据实际差值范围为−89.49至+86.09个百分点；原色带端点为±50，8个单元超出端点，且全部属于低支持组合。单画框方案推荐共用−90至+90的完整对称线性色带，刻度可用−90、−60、−30、0、+30、+60、+90，覆盖所有原始点估计，不截断差异幅度。

低支持单元继续用细斜线明确提示；深色本身不作为稳健证据。正文减碳案例的中等色深由稳定点和简短读数辅助识别，不对该行另设独立色标。若正式缩印后色深不足以分辨，优先调整红蓝端色及对比度，不删除大幅低支持估计或隐藏色带饱和。

## 7 类别比较的解释边界

三类分别按各国自身的目标CLR点估计划分：低位M<−0.5，近似相称−0.5≤M≤0.5，高位M>+0.5。当前近似相称类别中，NSF包含SDG3、7，NSFC包含SDG3、7、9、12。因此，图中同名类别不表示两国比较的是完全相同的SDG集合。

既有全局Target—时间平衡也不能自动解释为每个类别×需求内部的全部结构都已经一致。保持正文“两国各自供给与挑战近似相称的目标类别中……”的限定，避免改写成“同一SDG、同一Target内的纯国别效应”。

图中颜色表示条件任务份额差，不表示某项需求被满足的程度、国家挑战的主题级缺口、科研效果或因果影响。近似相称是CLR操作性类别，不是资助最优或任务配置相同的判定。5a的条件份额不能直接与5b的国家—SDG观测阶段份额相加闭合；二者提供不同层次的描述证据。

## 8 图注修订草案

**a，三类相对供给位置中的需求—知识任务差异。** Target及资助时间熵平衡后，展示19项城市需求在六类知识任务上的NSF−NSFC条件份额差，单位为百分点。三类分别由各国自身SDG的CLR偏离点估计M<−0.5、−0.5≤M≤0.5及M>+0.5界定，各国同名类别可包含不同目标。红、蓝分别表示NSFC、NSF条件份额较高。斜线表示任一国项目族有效样本量ESS<10，窄列给出两国较小ESS的显示近似值；点表示两国ESS均≥10、项目族Bootstrap 95%区间不跨零且342单元BH校正q<0.05。项目族Bootstrap为2,000次；逐单元估计、有效重复数、区间、校正结果和精确ESS见表S20及补充数据3。

Figure 5b及其图注的分析内容不因此次5a排版整合而改变。保留现行4.4的减碳解释，可以酌情增加上述两项差值读数；无需为改画框而改写摘要、研究问题或结论。
