# 第 3 步：Figure 5b 多和弦图重设计方案（已执行；按用户复核修正）

用户已选择 modelviz 的 `net_chord_relationship`（关系和弦图）模板，并接受图面展示**邻层加权连接**、原始完整路径在数据表中保留的表示方式。原有 `b` 标识、主标题及 `Project-count stability gate` 表述保持不变。

## 主图版式

1. 以三行相对位置（Relative lower / Near alignment / Relative higher）×两列国家（NSF / NSFC）排列**六个和弦图**，每图对应原图的一个面板。为保证 21–23 个节点的标签可读，合成图采用 A3 纵向画布，同时提供六幅可单独放大的面板图。
2. 用户复核后明确要求圆内不要出现 `SDG11` 这样的 SDG 节点。因此每图环上只保留正式 Target、K01–K06、A01–A07 三组节点；入选 SDG 在面板外以 `Goals 11, 13` 之类的文字说明。
3. 由原始 753 条完整路径分别汇总 Target–K 和 K–A 两类邻层关系，权重为 `fractional_project_support` 之和。六图共有 397 条非零汇总弦，每条原始路径都计入两个关系矩阵。环弧在**同一节点层内**反映支持量大小；知识任务层同时承接入弦和出弦，环弧长度不可跨层直接比较。
4. NSF 沿用 Figure 1a 的 `#003366`–`#7F99B2`–`#E4EDF5` 蓝色阶，NSFC 沿用 `#8B0000`–`#C57F7F`–`#F6E4E4` 红色阶；连接强度以同色系的宽度和透明度呈现，细线先画、强连接后画。全部非零连接保留。
5. 用户第二次复核后要求去除独立的底部行动阶段图。六个和弦图各自增加一个 100% 外环，按 A01–A02、A03–A04、A05–A07 的真实占比连续分段。最新复核要求把三组精确百分比从圆心移到每图左下角的小图例。这部分仍由原始路径计算，不从和弦宽度估算。

## 图注与限制

- 标明：和弦是 Target–K、K–A 支持量的汇总，**不能沿单条弦追踪一个完整的 SDG→Target→K→A 四层路径**；完整 753 条路径随数据文件交付。SDG 仅定义各面板内容，不作为圆内扇区。
- 标明：宽度编码分数项目支持量；六个面板分别归一化排版，不能根据屏幕上的弦宽直接比较不同面板的绝对支持量。
- 避免把关系理解为项目真实的时间连续过程。
