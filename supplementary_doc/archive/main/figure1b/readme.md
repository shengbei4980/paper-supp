# Figure 1e：中心雷达、双层弧形覆盖条与 34 根外环柱

本次最终输出为 `图/Figure1e_双层弧形覆盖条_深蓝深红版`，包含 PNG、PDF、SVG、TIFF。内圆上方分 SDG、Target、Need domain 三个扇区，各有外侧 Overlap 和内侧 JSD 两层覆盖条。放大的 Target 雷达恢复居中，外环保留 34 根柱。旧版图保留供对照。

本版按确认方案将 15 个跨层级 Top-5 类别与 19 项具体需求合并为 34 根外环柱。类别只显示编号与柱端数值；完整名称见 `编号全称释义表.md` 和 `数据/Figure1e_外环编号全称释义表.csv`。

## 图的编码

- 所有柱从同一圆形基线向外增长，径向柱长使用共同的 0–45% 线性刻度，表示该类别对其所属层级总 JSD 的贡献占比。不同层级分别有各自的 JSD 分母。
- 正号和蓝色表示 NSF 的类别份额较高；负号和红色表示 NSFC 的类别份额较高。贡献大小本身非负；这不是两国份额之差。S13 的贡献占比为 18.233979%，显示为 +18.2%。数值显示一位小数，低于 0.05% 的值显示为 0.0%。
- 保留源表的 Bootstrap 95% 区间。15 个 Top-5 项的有符号区间均未跨零，因此可以将其两端的绝对值按大小排序用于非负柱高。19 项具体需求直接使用原始非负贡献区间。
- 按用户最新确认采用 Figure1a 深蓝 #003366、深红 #8B0000，柱体、轮廓、数字与图例同步，不透明度为 1。
- 每条底轨跨度为 50°，浅灰底轨配深灰覆盖弧段，顺时针填充。Overlap 按原始系数 / 1 定义覆盖比例，显示为百分比；JSD 按原始值 / 0.16 定义覆盖比例，显示原始小数。每个指标在三个层级间共用刻度、半径和条宽；不同指标之间不比较覆盖长度。数值在底轨中点对齐，Target 组名称与数值加粗。JSD 越低、Overlap 越高表示组成越相似。
- 所有圆形边界及圆形辅助线统一为黑色，以线宽区分主边界与辅助线。中心沿用原始 30 个 Target 雷达数据和绘图函数。中心雷达使用深蓝 #003366 实线表示相对差异，深红 #8B0000 虚线表示平方根缩放的 JSD 贡献；此处颜色区分指标，外环颜色表示较高份额的国家。中心 Top-5 标记按国家使用深蓝 #003366、深红 #8B0000，背景强调使用相应浅色 #E4EDF5、#F6E4E4，均不叠加透明度。父级分组背景使用 Figure1a 的 #F7F8FA 与 #EEF1F4。

## 复现与检查

使用已安装 numpy、pandas、matplotlib、scipy 的 Python 环境运行：

```powershell
python .\代码\绘制Figure1e_统一外环柱状图.py
```

入口自检覆盖 34 根柱、30 个中心 Target、12,000 行 Bootstrap 数据、6 项内圆指标、置信区间完整包含、全部柱区间位于 0–45% 刻度内以及 S13 数值。六项指标直接读取原始跨层级汇总表。最终 PNG 检查指标组与外环编号、雷达之间的间距；34 项外环只显示编号及数值。
