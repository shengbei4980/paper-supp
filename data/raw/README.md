# Raw data scope

No separate, identifiable uncoded grant-database export was supplied in the source folder. This directory is retained to make the requested repository structure explicit; it does not contain invented or relabeled raw data.

The NSF/NSFC coding-results and coding-evidence exports are processed research data, stored under `../processed/coding/`. Figure input snapshots are also retained under `../processed/` because being an input to a plot does not by itself make a file original raw data.
